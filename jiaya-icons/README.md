# 家压小程序图标包

- `png-original/`：原始 1254 × 1254 PNG，透明背景（已 gitignore，不入库）。
- `png-256/`：适合小程序直接引用的 256 × 256 PNG。
- `preview.png`：全部图标预览。

运行时资源已复制到：`apps/miniapp/src/assets/icons/`，通过 `AppIcon` 组件与 `ICONS` 常量引用。

图标命名：

1. `app-logo.png`：家压品牌/健康守护
2. `home.png`：首页
3. `health-report.png`：健康报告
4. `family.png`：家人/家庭
5. `profile.png`：我的/个人
6. `history.png`：历史记录
7. `trend.png`：趋势数据
8. `reminder.png`：提醒设置
9. `privacy.png`：隐私安全
10. `add-record.png`：新增/记录血压
